# Zan Orthodontics Website

Modern, responsive website for an orthodontic practice built with Next.js, React, and Tailwind CSS.

## Overview

This project is a professional website for Zan Orthodontics, featuring:

- A clean, modern design with a focus on patient experience
- Responsive layout that works on all devices
- Information about services, operating hours, and contact details
- Component-based architecture for maintainability

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide](https://lucide.dev/)

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm, yarn, or pnpm

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/zanV2.git
   cd zanV2
   ```

2. Install dependencies
   ```bash
   cd my-app
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Run the development server
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the website

## Project Structure

- `my-app/app/` - Next.js application pages and layout
- `my-app/components/` - Reusable UI components
- `my-app/components/ui/` - Base UI components built with shadcn/ui
- `my-app/public/` - Static assets like images and icons

## Features

- **Modern Design**: Clean, professional design with a calming blue color palette
- **Responsive Layout**: Optimized for mobile, tablet, and desktop
- **Key Sections**:
  - Hero section with call-to-action
  - Operating hours
  - Mission and vision
  - Services offered
  - "Why Choose Us" highlighted features
  - Contact form and information
  - Footer with practice information

## Deployment

The site can be deployed with Vercel:

```bash

# then deploy according to your hosting provider
```
